SortingApp

Консольное Java-приложение для управления коллекцией студентов, их сортировки и анализа. Разработано в рамках учебного проекта с упором на чистую архитектуру, паттерны проектирования и тестирование.

🚀 Основные возможности

Управление данными: Создание и хранение объектов Student (номер группы, средний балл, номер зачетной книжки).

Ввод данных: Три способа заполнения коллекции:
Вручную через консоль.
Случайная генерация (Random).
Загрузка из JSON-файла.

Сортировка: Сортировка по трем полям (номер группы, средний балл, номер зачетки), а также специальная сортировка (четные/нечетные номера зачеток).

Многопоточность: Подсчет вхождений конкретного студента в коллекцию с использованием многопоточности (ExecutorService).

Сохранение: Дозапись отсортированных данных в JSON-файл.

🏗 Архитектура и паттерны
Проект построен по принципам чистой архитектуры (Layered Architecture) с использованием внедрения зависимостей (DI).

Паттерн Стратегия: Используется для выбора алгоритмов сортировки (Sort) и источников данных (Provider). Реализовано через Map для гибкости.

Паттерн Строитель (Builder): Используется в классе Student (совместно с аннотациями Jackson для десериализации).

Паттерн Композиция: Service выступает как оркестратор, делегируя работу специализированным классам.

Кастомная коллекция: Реализован собственный CustomList, наследующий AbstractList.

Структура пакетов:
model — доменная модель (Student).
collection — кастомная коллекция (CustomList).
provider — источники данных (Console, File, Generated).
sort / comparator — алгоритмы сортировки и компараторы.
repository — in-memory хранилище данных.
service — бизнес-логика (оркестратор).
menu — консольный интерфейс (Controller).
printer — вывод данных в консоль.
input — обработка пользовательского ввода.
counter — многопоточный подсчет вхождений.
saver — сохранение данных в JSON.

🛠 Технологии
Java 21 (используются record, switch-выражения, streams).
Maven (управление зависимостями).
Jackson (работа с JSON).
JUnit 5 (модульное тестирование).

🧪 Тестирование
Покрытие тестами (JUnit 5) включает в себя:
Валидацию модели Student.
Работу кастомной коллекции CustomList (включая расширение массива).
Логику сортировок (стратегии).
Защитное копирование в Repository.
Многопоточный подсчет в OccurrenceCounter.
Перехват вывода консоли в ConsolePrinter.
Обработку пользовательского ввода в StudentInput.
Для запуска тестов выполните:
bash
mvn test

🚦 Как запустить
Убедитесь, что у вас установлена Java 21 и Maven.
Клонируйте репозиторий.
В корневой директории проекта выполните:
bash
mvn clean compile exec:java -Dexec.mainClass="ru.aston.team.one.sortingapp.Main"
(Или просто запустите класс Main из вашей IDE).
